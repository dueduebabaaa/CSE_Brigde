# BRIDGE — 전체 서비스 기능 명세서 (SERVICE_SPEC.md)

## 1. 서비스 개요
- **서비스명**: BRIDGE (브릿지)
- **영문 슬로건**: BEYOND CONNECTION.
- **한글 슬로건**: 우리 사이, 가능성을 잇다.
- **서브 타이틀**: KNU CSE · PROJECT NETWORK
- **서비스 대상**: 경북대학교 컴퓨터학부 재학생 및 대학원생
- **대표 컬러**:
  - Black: `#000000` (배경 `#0B0C10`, 카드 `#13141C`)
  - Violet: `#7D39EB` (메인 포인트)
  - Lime: `#C6FF33` (강조 포인트 및 액션)
  - White: `#FFFFFF`

## 2. 10대 핵심 기능 상세 명세

### 2-1. 홈 대시보드 (`/`)
- **담당**: 팀원 A (UI/UX) + 팀원 C (추천)
- **주요 기능**:
  - 학생 개인별 관심 분야와 기술 스택에 최적화된 맞춤형 활동 추천 피드
  - 경북대 컴퓨터학부 공식 홈페이지에서 수집된 최신 공지 실시간 알림
  - 공식 공고 데이터의 최근 업데이트 일시 표시 (예: "최근 수집: 2026-11-15 00:00 KST")
  - 최근 등록된 팀원 모집 게시글 퀵 리스트
  - 마감 임박 공모전 D-Day 카운트다운 배너
  - 내가 참여 중인 팀 프로젝트 현황 위젯 및 다가오는 미팅 일정 표시
  - 서비스 핵심 기능 바로가기 카드

### 2-2. 회원가입 및 로그인 (`/login`, `/signup`)
- **담당**: 팀원 B (Supabase Auth & DB) + 팀원 A (온보딩 UI)
- **주요 기능**:
  - Supabase Auth 기반 이메일/비밀번호 회원가입 및 로그인
  - 로그인 세션 유지 (Local Storage / Supabase Session)
  - 추후 경북대학교 공식 웹메일(`@knu.ac.kr`) 인증 확장 인터페이스 설계
  - 사용자별 데이터(프로필, 북마크, 참여 팀) 보안 분리 (RLS 적용)

### 2-3. 컴퓨터학부 공식 공고 자동 수집
- **담당**: 팀원 B (Node.js 크롤러 & GitHub Actions)
- **수집 대상**: 경북대학교 컴퓨터학부 공식 홈페이지(`https://computer.knu.ac.kr/`) 공개 공지사항
- **수집 항목**:
  - 공고 고유 ID (`sourcePostId`), 제목, 분류, 게시일, 모집 시작일, 모집 마감일
  - 주최기관, 활동 분야, 지원 자격, 모집 인원, 핵심 요약 내용
  - 원본 게시글 링크(`sourceUrl`), 공식 신청 페이지 링크(`applicationUrl`)
  - 데이터 수집 시간, 최근 업데이트 시간, 모집 상태
- **수집 정책 & 안전 수칙**:
  - 홈페이지 이용약관 및 `robots.txt` 준수, 과도한 요청 방지(Throttling)
  - 공식 API 또는 RSS가 제공되는 경우 크롤러보다 우선 사용
  - 제목/본문 키워드 필터링을 통해 공모전·대외활동·해커톤 공지만 선별 (일반 학사/수강신청/등록금 공지 제외)
  - 중복 저장 방지: 고유 ID 또는 원본 URL 해시 기준 upsert
  - 마감일 미확인 시 임의 날짜 생성 금지 (`deadline: null`, `status: needs_confirmation`)
  - 원문 전체 복제 금지(요약 및 원본 링크 제공 원칙)
  - 1일 1회 GitHub Actions 자동 수집 및 관리자 수동 수집(`admin_manual`) 지원

### 2-4. 공모전 및 대외활동 탐색 (`/opportunities`, `/opportunities/:id`)
- **담당**: 팀원 A (목록/상세 UI) + 팀원 B (공고 CRUD API) + 팀원 C (추천 점수)
- **주요 기능**:
  - 학부 공식 수집 공고(`knu_cse_official`), 관리자 등록 공고(`admin_manual`), 사용자 직접 등록 공고(`user_manual`) 출처 명확히 구분
  - 공고 검색 (제목, 주최기관, 기술 태그)
  - 유형별(해커톤, 경진대회, 대외활동, 교육/특강 등) 및 상태별 필터링
  - 마감 임박순 / 최신순 / 내 맞춤 추천순 정렬
  - 공고 상세 페이지: 학부 원문 링크, 공식 신청 페이지 연결, 북마크 보관
  - 공고 상세 페이지 내 연계 기능:
    - 해당 공모전을 타겟으로 생성된 팀원 모집글 목록 조회
    - 해당 공모전 팀원 모집글 작성 바로가기
    - 해당 공모전에 적합한 학부생 추천 목록 표시

### 2-5. 팀원 모집 게시판 (`/recruitments`, `/recruitments/new`, `/recruitments/:id`, `/recruitments/:id/edit`)
- **담당**: 팀원 A (게시판/폼 UI) + 팀원 B (Supabase DB & 권한)
- **주요 기능**:
  - 팀원 모집글 작성, 조회, 수정, 삭제 (작성자 본인만 수정/삭제 가능)
  - 기존 등록 공모전 연계 또는 미등록 외부 활동 자율 입력 지원
  - 모집 인원, 모집 역할(Frontend, Backend, ML, Designer 등), 요구 기술 스택, 마감일, 온/오프라인 활동 방식 설정
  - 다른 사용자의 팀 가입 신청(`Application`) 제출
  - 모집자의 지원서 실시간 열람, 수락 및 거절 처리
  - 승인된 지원자를 팀원으로 자동 등록하고 팀 워크스페이스 생성 연동

### 2-6. 팀원 탐색 및 매칭 (`/members`, `/members/:id`)
- **담당**: 팀원 A (탐색 UI) + 팀원 C (매칭 적합도 알고리즘)
- **주요 기능**:
  - 프로필 공개에 동의한(`isPublic: true`) 학부생 전체 프로필 탐색
  - 팀원 이름 및 닉네임 부분 일치 검색
  - 세부전공(플랫폼소프트웨어, 데이터사이언스, 인공지능컴퓨팅 등), 학년, 희망 역할별 필터
  - 관심 분야, 기술 스택, 희망 역할, 공통 활동 가능 시간을 종합한 매칭 적합도(0~100%) 및 추천 이유 표시
  - 팀장 권한 사용자의 다이렉트 팀 초대장(`Invitation`) 발송 및 수신자의 수락/거절

### 2-7. 스마트 팀 빌더 (`/team-builder`)
- **담당**: 팀원 C (팀 밸런스 분석 알고리즘) + 팀원 A (Recharts 시각화 UI)
- **주요 기능**:
  - 팀원 후보 추가 및 제거에 따른 실시간 시뮬레이션
  - 현재 팀의 기술 역량 커버리지 다각형 레이더 차트 시각화
  - 팀 내 필수 역할 충족 여부 및 결손 포지션(예: Backend 부재) 경고
  - 부족한 역량을 완벽하게 채워줄 추천 인재 1-Click 영입 제안
  - 팀원 구성 변동에 따른 주간 공통 가능 시간(회의 가능 슬롯) 변화 분석
  - 최종 확정된 팀 구성 저장 및 프로젝트 생성

### 2-8. 주간 시간표 및 일정 조율 (`/schedule`)
- **담당**: 팀원 C (시간표 교차 계산 알고리즘) + 팀원 A (인터랙션 UI)
- **주요 기능**:
  - 한국 시간(Asia/Seoul) 기준, 월~일 주간 48개 슬롯(30분 단위) 개인 가능 시간 등록
  - 클릭 및 마우스 드래그를 통한 간편한 슬롯 토글
  - 팀원 전원의 시간표를 교차 비교하여 5단계 히트맵 시각화
  - 팀원 전원이 참여 가능한 연속 1~2시간 최적 회의 슬롯 자동 추천
  - 전원 가능 슬롯이 없을 경우, 최대 인원이 참여 가능한 차선 슬롯 추천
  - 확정된 추천 슬롯을 팀 회의 일정(`Meeting`)으로 즉시 저장

### 2-9. 내 프로젝트 (`/projects`, `/projects/:id`)
- **담당**: 팀원 A (프로젝트 대시보드 UI) + 팀원 B (실시간 동기화)
- **주요 기능**:
  - 내가 속한 활성 프로젝트 및 과거 완료 팀 목록 관리
  - 공모전 제출 마감일까지 남은 D-Day 표시
  - 팀원 명단 및 담당 역할 확인
  - 팀 공동 작업 체크리스트(`ProjectTask`) 항목 추가, 완료 체크, 담당자 지정
  - GitHub 레포지토리, Figma, 화상 회의 링크 등 협업 도구 연동

### 2-10. 마이페이지 & 프로필 설정 (`/profile`, `/bookmarks`)
- **담당**: 팀원 A (프로필 UI) + 팀원 B (프로필 CRUD)
- **주요 기능**:
  - 이름, 닉네임, 학년, 세부전공, 자기소개, 보유 기술, 배우고 싶은 기술, 프로젝트 이력 관리
  - GitHub 및 포트폴리오 웹사이트 링크 등록
  - 프로필 공개 범위 설정 (전체 공개 / 비공개 토글)
  - 내가 작성한 팀원 모집글, 보낸 가입 신청서 상태, 받은 팀 초대장 수락/거절 관리
  - 북마크한 공모전 보관함 확인

## 3. 관리자 전용 기능 (`/admin/opportunities`)
- **담당**: 팀원 B (크롤러 & 관리자 API)
- 관리자 권한(`Admin Role`) 보유자만 접근 가능
- 학부 홈페이지 공고 수동 즉시 수집 트리거 (`workflow_dispatch` 연동)
- 크롤링 성공/실패 로그(`CrawlingLog`) 및 신규/수정 건수 실시간 모니터링
- 홈페이지 구조 개편 등 비상 상황 시 관리자 직접 공고 등록(`admin_manual`) 지원
