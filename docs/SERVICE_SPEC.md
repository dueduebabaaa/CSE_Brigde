# BRIDGE — 전체 서비스 기능 명세서 (SERVICE_SPEC.md)

## 1. 서비스 개요
- **서비스명**: BRIDGE (브릿지)
- **서비스 정의**: 경북대학교 컴퓨터학부 학생들을 위한 통합 프로젝트 네트워킹 플랫폼
- **영문 슬로건**: BEYOND CONNECTION.
- **한글 슬로건**: 우리 사이, 가능성을 잇다.
- **서브타이틀**: KNU CSE · PROJECT NETWORK
- **서비스 대상**: 경북대학교 컴퓨터학부 재학생 및 대학원생
- **핵심 가치**:
  - **발견 (Discovery)**: 학부 공지 및 교내외 기회의 탐색과 추천
  - **연결 (Connection)**: 최적의 동료 매칭 및 팀 구성
  - **협업 (Collaboration)**: 공통 시간표 조율 및 프로젝트 완주 지원
- **대표 컬러**:
  - Black: `#000000` (배경 `#0B0C10`, 사이드바 `#0A0A0C`, 독립 로그인)
  - Violet: `#7D39EB` (메인 포인트 및 네비게이션)
  - Lime: `#C6FF33` (강조 포인트 및 액션)
  - White: `#FFFFFF` (깨끗한 화이트 중심의 콘텐츠 캔버스)

## 2. 인증 및 계정 관리 시스템 (ACCOUNT)

> [!IMPORTANT]
> **로그인 방식 변경 안내 (이메일/비밀번호 $\rightarrow$ 경북대학교 Google 간편 로그인)**
> - 기존 이메일/비밀번호 회원가입 방식을 폐지하고, **경북대학교 Google 계정(`@knu.ac.kr`) 기반 간편 로그인**으로 일원화합니다.
> - 학교 구글 계정 연동은 학생 신분을 검증하는 1차 관문 역할을 수행합니다.

### 2-1. Google OAuth 간편 로그인 (`/login`)
- **담당**: 팀원 B (Google OAuth & Supabase Auth) + 팀원 A (로그인 UI)
- **주요 기능**:
  - Google OAuth 2.0 + Supabase Auth 기반 로그인
  - `@knu.ac.kr` 학교 계정만 서비스 접근 허용 (일반 Gmail 및 타 대학 계정 차단)
  - 웹사이트 최초 접속 시 Google 로그인 화면을 표시하며, **비로그인 사용자의 내부 페이지 직접 접근을 전면 제한**
  - 기존의 별도 이메일/비밀번호 회원가입 화면(`/signup`)은 점진적으로 제거/리다이렉트 처리
  - 로그인 세션 유지 및 로그아웃 시 최초 로그인 화면으로 이동
  - 서버 측(Edge Function / RLS)에서 도메인 일치 검증을 수행하여 비정상 세션 차단
  - *비상 대체 수단*: 학교 Google 계정의 외부 앱 연동 권한이 정책상 차단되는 경우, 학부 이메일 매직 링크 인증 방식을 대체 방식으로 검토

### 2-2. 초기 프로필 설정 화면 (Onboarding Wizard)
- **담당**: 팀원 A (온보딩 인터랙션 UI) + 팀원 B (프로필 레코드 생성)
- **주요 기능**:
  - Google 인증 완료 시, 최초 가입 사용자인지 확인
  - **신규 사용자**: 초기 프로필 설정 화면으로 강제 이동
    - 학교 이메일 인증과 컴퓨터학부 재학생 인증을 구분하여, 학부 소속(컴퓨터학부) 및 세부전공을 직접 입력
    - 학년, 관심 분야, 보유 기술 스택(아직 보유 기술 없음 선택 가능), 희망 역할 입력
  - **프로필 설정 완료 후**: 자동으로 홈 대시보드로 이동
  - **기존 사용자**: 로그인 성공 시 온보딩을 건너뛰고 즉시 홈 대시보드로 이동

## 3. 전체 메뉴 체계 및 상세 기능 명세

### 3-1. WORKSPACE (핵심 작업 공간)

#### 1) 홈 대시보드 (`/`)
- **담당**: 팀원 A (UI/UX) + 팀원 C (추천)
- **주요 기능**:
  - 사용자 프로필 기반 **맞춤형 공모전 추천** 피드 (추천 점수 및 추천 이유 표기)
  - 경북대 컴퓨터학부 공식 홈페이지 **최신 학부 공고** 실시간 피드
  - 공식 데이터 최근 수집 일시 표시 (예: "최근 수집: 2026-11-15 00:00 KST")
  - 마감 임박 공모전 D-Day 카운트다운 배너
  - 최근 등록된 팀원 모집 게시글 퀵 리스트
  - 추천 팀원 목록 및 주요 기능 바로가기 카드

#### 2) 공모전 및 대외활동 (`/opportunities`, `/opportunities/:id`)
- **담당**: 팀원 A (UI) + 팀원 B (공고 CRUD API) + 팀원 C (추천 알고리즘)
- **주요 기능**:
  - 컴퓨터학부 공식 공고 자동 수집(`knu_cse_official`), 관리자 직접 등록(`admin_manual`), 사용자 직접 등록(`user_manual`) 출처 명확히 구분
  - 공고 제목 및 키워드 검색, 카테고리(해커톤, 공모전, 경진대회, 대외활동 등) 필터
  - 최신순, 마감 임박순, 맞춤 추천순 정렬
  - 공고 상세 정보: 학부 원문 공지 링크, 주최측 공식 접수 링크 제공
  - 관심 공고 북마크 저장 및 해제
  - **공고 상세 내 연계**:
    - 해당 공모전에 대한 팀원 모집글 조회 및 즉시 작성 연결
    - 해당 공모전에 적합한 학부생 추천 목록 표시

#### 3) 팀원 모집 게시판 (`/recruitments`, `/recruitments/new`, `/recruitments/:id`, `/recruitments/:id/edit`)
- **담당**: 팀원 A (게시판 UI) + 팀원 B (Supabase DB & RLS)
- **주요 기능**:
  - 팀원 모집글 작성, 조회, 수정, 삭제 (작성자 본인 권한 제어)
  - 기존 등록된 공모전 공고와 모집글 연계
  - 등록되지 않은 공모전 제목 및 외부 링크 직접 입력 지원
  - 일반 프로젝트 및 스터디 모집글 작성 지원
  - 모집 인원, 모집 역할(Frontend, Backend, AI 등), 필요 기술 스택, 마감일, 활동 방식(대면/비대면/혼합) 설정
  - 모집 상태(모집중, 모집완료) 표시
  - 타 사용자의 팀 가입 신청(`Application`) 및 작성자의 수락/거절 승인

#### 4) 팀원 탐색 (`/members`, `/members/:id`)
- **담당**: 팀원 A (탐색 UI) + 팀원 C (매칭 알고리즘)
- **주요 기능**:
  - 프로필 공개에 동의한 학부생 전체 프로필 열람
  - 이름 및 닉네임 부분 일치 실시간 검색
  - 학년, 세부전공, 관심 분야, 기술 스택, 희망 역할 다중 필터
  - 맞춤형 팀원 매칭 적합도(0~100%) 및 추천 사유 표시
  - 팀원 상세 프로필(자기소개, 기술 숙련도, 프로젝트 경험, 링크) 조회
  - 팀 빌더 후보 즉시 추가 기능

### 3-2. COLLABORATION (팀 협업 도구)

#### 1) 스마트 팀 빌더 (`/team-builder`)
- **담당**: 팀원 C (역량 분석 알고리즘) + 팀원 A (시각화 UI)
- **주요 기능**:
  - 프로젝트별 필요 역할 및 기술 스택 요구사항 설정
  - 팀원 후보 추가 및 제거에 따른 실시간 시뮬레이션
  - 현재 팀의 역할 충족률(Coverage Ratio) 및 전체 기술 스택 분석
  - 부족한 역할(예: 백엔드 부재) 및 부족한 기술 역량 분석
  - 부족한 역량을 완벽히 보완할 수 있는 추천 팀원 인재 제안
  - Recharts 기반 다각형 레이더 차트 및 역할별 역량 시각화
  - 팀원 구성 변동 시 팀 적합도 및 공통 가능 시간 실시간 재계산
  - 최종 확정 팀 구성 저장 및 프로젝트 개설 연동

#### 2) 주간 시간표 조율 (`/schedule`)
- **담당**: 팀원 C (시간표 최적화 알고리즘) + 팀원 A (인터랙션 UI)
- **주요 기능**:
  - 한국 시간(Asia/Seoul) 기준, 월~일 주간 48개 슬롯(30분 단위) 개인 활동 가능 시간 입력
  - 마우스 드래그를 통한 간편한 시간 선택
  - 팀원별 활동 가능 시간 비교 및 전원 참여 가능 시간 자동 계산
  - 참여 가능 인원 수에 따른 5단계 히트맵 시각화
  - 연속 1시간 및 2시간 이상 회의 가능한 최적 시간 슬롯 추천
  - 전원 참여가 어려울 경우, 최대 인원이 참여 가능한 차선 시간 슬롯 추천
  - 상세 시간표는 본인 및 팀원 접근 권한에 따라 공개

#### 3) 내 프로젝트 (`/projects`, `/projects/:id`)
- **담당**: 팀원 A (워크스페이스 UI) + 팀원 B (실시간 데이터)
- **주요 기능**:
  - 내가 참여 중인 팀 및 프로젝트 목록 관리
  - 프로젝트 상세 정보: 참여 공모전 정보, 팀원 명단 및 담당 역할
  - 마감일까지 남은 기간(D-Day) 및 회의 일정 표시
  - GitHub, Figma, 화상 회의 등 협업 링크 등록 및 이동
  - *추가 기능*: 간단한 프로젝트 체크리스트 및 프로젝트 진행률(%) 관리

## 4. 컴퓨터학부 공고 자동 수집 요건 (CRAWLER)
- **수집 대상**: 경북대학교 컴퓨터학부 공식 홈페이지(`https://computer.knu.ac.kr/`)
- **수집 방식**: 공식 API/RSS 제공 여부 우선 검토 $\rightarrow$ 부재 시 Node.js + Cheerio 활용
- **실행 환경**: 서버 환경 (GitHub Actions 정기 스케줄) 실행, 프론트엔드 실행 금지
- **준수 원칙**:
  - `robots.txt` 및 이용약관 확인 후 허용 범위 내 수집
  - 로그인/인증이 필요한 정보 수집 금지
  - 요청 간격(Throttling) 적용으로 학부 서버 부하 방지
  - 공모전/해커톤 관련 키워드 기반 선별 (일반 학사/수강신청/등록금 제외)
  - `sourcePostId` 기반 중복 저장 방지 및 수정 공고 업데이트 (Upsert)
  - 마감일 미확인 시 임의 생성 금지 (`deadline: null`, `status: needs_confirmation`)
  - 요약 및 원본 링크 제공 원칙 (전문 무단 복제 금지)
  - 수집 실패 시 기존 데이터 보존

## 5. 개인정보 보호 원칙
- **학교 이메일**: 타 일반 사용자에게 절대 공개하지 않음
- **이름 및 소속**: 사용자 동의에 따라 공개 범위 설정
- **관심 분야 및 기술 스택**: 프로필 공개 설정에 따름
- **상세 활동 가능 시간**: 본인 및 접근 권한이 있는 팀원에게만 공개
- **수집 배제 항목**: 학번, 주민등록번호, 전화번호, 생년월일은 일체 수집하지 않음
- **보안 격리**: 인증 데이터와 일반 공개 프로필 데이터를 분리하고 비밀 키를 GitHub에 업로드 금지
